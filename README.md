# SIGRIEA - Prototipo

Este repositorio contiene un prototipo interactivo (React + Tailwind) del sistema de gestión de condominios SIGRIEA. Es 100% frontend — sin backend — y simula roles (Administrador, Residente, Vigilante) y un simulador global de morosidad que altera el comportamiento de la aplicación.

Para ejecutar:

1. npm install
2. npm run dev

Diseñado por Copilot + Senior Frontend Developer (prototipo entregado bajo solicitud).
